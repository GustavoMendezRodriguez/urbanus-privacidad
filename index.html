Política de privacidad de Urbanus Data

Actualización: 26 de octubre de 2026

Urbanus Data gestiona respuestas a comentarios de @urbanus.lab. La automatización funciona desde el computador del responsable cuando está en ejecución.

Quién gestiona el servicio

Urbanus Lab gestiona Urbanus Data para su cuenta de Instagram @urbanus.lab. Para consultas sobre privacidad y solicitudes de eliminación, escribe a jgmendez@urbanuschile.com.

Para qué se utiliza

El servicio permite consultar comentarios de publicaciones de la cuenta y está destinado a responder por mensaje privado a quienes comenten en las publicaciones seleccionadas y aún no tengan una respuesta de @urbanus.lab. La respuesta contiene un enlace a www.datainmobiliaria.cl. Durante la configuración se realizan pruebas de acceso a la API de Instagram.

Qué datos se procesan

Se procesan los datos que Instagram facilita para estas operaciones: identificadores de cuenta, publicación y comentario, texto del comentario, fecha y datos necesarios para dirigir la respuesta. Para comprobar resultados y evitar duplicados, el servicio puede registrar el identificador del comentario y el estado y fecha del envío. No solicitamos contraseñas ni códigos de acceso a los seguidores.

Uso y acceso

Los datos se utilizan para atender la solicitud de información, comprobar el funcionamiento y evitar envíos duplicados. No se venden ni se utilizan para crear listas de publicidad ajenas a esta solicitud. El acceso de administración corresponde al responsable del servicio. Meta procesa los comentarios y mensajes conforme a sus propias políticas.

Conservación

Se conserva únicamente la información necesaria para atender las solicitudes, evitar duplicados y resolver incidencias. Los registros de diagnóstico se eliminan cuando dejan de ser necesarios para la prueba o incidencia correspondiente. Los registros automáticos de identificadores, estado y fecha se conservan por 30 días y se eliminan en la siguiente ejecución del programa. No se guarda el texto de los comentarios en estos registros. Los comentarios y mensajes que permanecen en Instagram se gestionan también desde esa plataforma.

Solicitar eliminación o dejar de recibir respuestas

Escribe a jgmendez@urbanuschile.com con el asunto «Privacidad Urbanus Data», tu usuario de Instagram y tu solicitud. Puedes pedir acceso, corrección o eliminación de datos bajo nuestro control, o solicitar que no se te envíen nuevas respuestas automáticas. Verificaremos la solicitud con la información mínima necesaria. No envíes contraseñas ni códigos de verificación. Eliminar nuestros registros no elimina automáticamente comentarios o mensajes conservados por Instagram.

Página de privacidad y enlaces externos

Esta página informativa se aloja en GitHub Pages y no incluye formularios, publicidad ni herramientas de analítica añadidas por Urbanus Lab. GitHub puede procesar datos técnicos de las visitas conforme a su declaración de privacidad.

Data Inmobiliaria es una plataforma de terceros; Urbanus Data no la administra. Al abrir su enlace se aplican las políticas y condiciones de ese sitio.

Cambios

Esta política se actualizará cuando cambie el funcionamiento o el tratamiento de datos del servicio. La fecha de actualización figura al inicio.
